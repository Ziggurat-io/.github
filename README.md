# .github

Organisation-wide files for Ziggurat. `profile/README.md` is the front page of the GitHub organisation.

- `profile/assets/` holds the lockup in dark-mode and light-mode versions. The README picks one with `<picture>` and `prefers-color-scheme`.
- Brand values (Ink `#121417`, Clay `#ECE6DA`, Brass `#D2A64C`, Steel `#7F9DB9`, Paper `#EEEBE4`, Graphite `#1A1C1F`) match the landing site in `ziggurat.io`.
- An animated banner rendered with Manim will replace the static lockup later.
